# Página personal de Jeshua Aburto

Página de presentación personal para la guía S11 de Diseño de Sistemas en Internet.

## Contenido
- Presentación personal.
- Listas de habilidades e intereses.
- Imagen local.
- Enlaces a GitHub y YouTube.

## Archivos
- `index.html`: estructura de la página usando HTML.
- `estilos.css`: personalización visual con tema oscuro.
- `foto.jpg`: agrega tu fotografía en este archivo.

## Cómo ejecutar
1. Coloca `index.html`, `estilos.css` y `foto.jpg` en la misma carpeta.
2. Abre `index.html` con doble clic en tu navegador.
